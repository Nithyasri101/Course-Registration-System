# Course Registration System

A full-stack web application for managing course registration.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- HTML
- CSS
- JavaScript

## Features

- View available courses
- Register for a course
- View enrolled students
- RESTful APIs for course registration
- MySQL database integration

## Project Structure

- `src` - Spring Boot backend
- `frontend` - HTML, CSS and JavaScript frontend
- `database` - MySQL database SQL file

## Backend

The backend is developed using Java and Spring Boot with Spring Data JPA and Hibernate for database operations.

## Frontend

The frontend is developed using HTML, CSS and JavaScript.

## Database

MySQL is used to store course and registration details.

## How to Run

1. Clone the repository.
2. Open the backend project in IntelliJ IDEA.
3. Configure MySQL database.
4. Import the SQL file from the `database` folder.
5. Run the Spring Boot application.
6. Open the frontend files in a browser or VS Code Live Server.
